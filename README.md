- Frontend: https://pikiora-frontend.onrender.com
- Django REST Framework API repository: https://github.com/12adisuji05/ISCG7420-Assignment2-DRF

Created with Create React App and written in JavaScript.

## Structure

- `src/index.js` - starts the app, adds Bootstrap and BrowserRouter
- `src/App.js` - routes for every page and the UserContext (token and logged-in user)
- `src/api.js` - address of the Django REST Framework API
- `src/components` - patient pages (doctors, booking, my appointments, login, register)
- `src/components/admin` - administrator dashboard (doctors, slots, appointments, patient accounts)

Each page calls the API with axios, using the request code generated by Postman.
The login token is sent in the `Authorization: Token <token>` header.

## Run on your computer

Start the Django API first (see the API repository), then:

```
npm install
npm start
```

Open http://localhost:3000.

## Deploy to Render

Static site. Build command: `npm install && CI=false npm run build`, publish directory: `build`,
environment variable `REACT_APP_API_URL=https://pikiora-clinic.onrender.com/api/`.
